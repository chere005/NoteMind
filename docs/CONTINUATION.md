# Continuation

- NoteMind 0.27.0 uses `.nm` for new Notepads and drawings; existing `.wm` archives remain readable. Projects use `.wmpr`.
- Mouse gestures in the sidebar mirror keep their initiating pointer, so native pen hover and lift cannot move or end them. The same ownership rule protects tablet strokes, camera ink, camera selections and document selections. Hidden checks exercise real mirror mouse drawing, selecting, moving, resizing, erasing and Undo with interleaved native pen hover.
- The Wacom switch recovers ownership left by an exited process or a previous boot. Edited pictures fit their own aspect ratio, and saved drawings retain the full supported 1:10–10:1 range. Hidden pad checks cover both toggle locations, stale ownership, full-size editing and forwarded drawing keys.
- Explore Features and Help → Welcome to NoteMind open an editable guide with a live checklist, table, drawing and two-page PDF. It lives in Documents/NoteMind and links into Default Workspace; only pristine generated guides refresh across releases. `--tour` opens it after restoring the session.
- Code blocks highlight the selected 24 language groups, including common aliases and JSX/TSX. Their language menu persists the Markdown fence; live colour updates keep the selection and skip IME composition. Cached explicit grammars avoid detection; code over 64K characters stays plain to bound synchronous work.
- Graphics panes store one image preview and compact editable stroke sidecars; see GRAPHICS-PANES.md. Pen, mouse, selection transforms, native button actions and drawing-location switching have hidden application coverage.
- Committed ink is immutable. Drawing paints new segments, eraser queries cache stroke bounds, selection drags reuse bitmaps, and dirty-state checks reuse stroke fingerprints. Image previews reuse binary URLs and cache header dimensions, including EXIF orientation, so deferred decoding cannot change the scroll range. Image-only notes retain an editable final paragraph.
- The large-document check uses 10,000 strokes, 200,000 points and 100 large images; it verifies incremental drawing, cached dragging, compact preview markup and complete autosave.
- The workspace adapts to narrow windows, remembers sidebar resizing and visibility, keeps active tabs visible and avoids rebuilding navigation while typing. Lists, Insert and Format hold writing actions; source selection belongs to the capture pane. Drawing location and orientation are icon controls.
- Sidebar creation uses one split plus. Linked files, drafts, search and pinned rows share working actions; deletion is recoverable through Recently Deleted, while Remove from Project keeps the file. Hidden sidebar-actions checks exercise the menu commands against real temporary files.
- Menu buttons toggle without timing thresholds and retain their identity across sidebar refreshes. Shared menus use their triggering window, keep live settings current, clamp and scroll within the viewport, and support submenu arrows, type-ahead, Escape and focus restoration. Hidden menu-audit and pen-display checks cover main-window and Wacom popups.
- `npm run preflight` runs the Node suite. `node test/validate-round.cjs source` and `node test/validate-round.cjs packaged` run hidden application checks; the portable executable check runs on Windows.
- `npm run build` creates the Apple Silicon application at `dist/NoteMind/NoteMind.app`, locally signed without notarization. Physical Wacom behavior and Windows packaging still require their respective hardware.
