# Bounded Word reference preview source

`src/word-preview-sessions.cjs` exports `WordPreviewSessions`. Main constructs it lazily with `{tempRoot, withForeground: run => notesIPC.foreground(run), onInvalidated(owner,token,error)}`. Optional workerFactory is for fault tests. No worker is created until the first open. One serial worker serves up to four owner-bound sessions, then actually exits when the last session releases. Cancellation/worker errors stop that worker, wait for its actual exit, and clean only journal-proven files before any replacement. Cancellation invalidates other tokens on that worker; the UI should reload an affected visible reference via onInvalidated.

- `open(owner,file,{requestId,signal})` returns `{kind:'docx', token, sourceRevision:{bytes,sha256}, segments:[{index,htmlBytes,continuation}], warnings}`.
- `segment(owner,token,index,{signal,requestId})` returns `{index,html,assets:[{id,mime}]}`. Each fragment is balanced HTML, normally about 256 KiB, with structural context overhead. No complete converted document or image strings cross this interface.
- `asset(owner,token,id,{signal,requestId})` returns `{id,url,mime}`. The file URL refers to original exact image bytes (TIFF is converted as in import), on demand; no resizing. Use the ID in `data-word-asset`, and assign its returned URL only while that DOM element/session is current. Dispose renderer URL/image references when a virtual segment leaves the viewport.
- `link(owner,token,id,{signal,requestId})` returns `{href}`. Links carry a short `data-word-link` ID, not a repeated long destination. Main must keep the existing external-link opening policy; the source renderer's safe-protocol filter already applies.
- `attribute(owner,token,id,{offset:0,maxBytes:65536,signal,requestId})` returns `{value,nextOffset,done}`. Exceptional long image alt strings are preserved in private UTF8 sidecars and referenced by `data-word-alt`; read using returned byte offsets, never concatenate every attribute eagerly. Ordinary alt text remains exact inline.
- `release(owner,token)`, `releaseOwner(owner)`, `cancel(owner,requestId)` and `dispose()` join owned cleanup. Foreign tokens cannot access/release another owner. Request cancellation is owner scoped. A resolved/rejected terminate promise is never an exit acknowledgment.

The UI must virtualize visible segments, request only their images, stop observers/fetches before releasing a token, and close the reference session on owner close. A continued structural element is annotated `data-word-continuation` when reopened in a later fragment. Suppress its duplicate list marker (`li[data-word-continuation]{list-style-type:none}`), reset continued first paragraph/heading margins, and suppress the continued last paragraph's end margin at a following fragment. Reopened ordered-list start counters preserve the current item. The streaming large-table route uses fixed column layout for consistent fragment widths; small documents preserve the full existing renderer oracle. Native layout proof is still required for the wired UI.

Ordinary bounded XML uses the exact pinned Mammoth -> current Turndown -> Markdown renderer semantics with image metadata references, without reading media. Large XML uses an additive sink on the existing Word visitor and shared paragraph/list/style decisions, not a second Word interpreter or a complete Markdown token graph. Held-FD source identity and full file SHA are checked before/after build; lazy media reopens and checks the captured exact identity and entry CRC/SHA. Segment payload SHA and FD/named stability guard returned HTML. Exact private inode claims protect cleanup; foreign siblings/replacements survive. No native or aggregate 477 MiB preview proof has run in this leaf; only focused Node 26 source/actual-worker checks.
